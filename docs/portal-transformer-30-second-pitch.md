## 1. Spoken Script (30 Seconds / ~75 Words)

"Portal Transformer is a security-constrained client extension that uses AI to fix web accessibility defects for screen-reader users. While LLMs can generate missing image alt text and icon labels, they risk prompt injection and credential theft. Portal Transformer solves this by placing zero-trust security boundaries around the AI—scrubbing sensitive data before dispatch and restricting DOM patches strictly to accessibility attributes. Across 20 government portals and 1,000 security attacks, it achieved 100% precision and zero unsafe mutations."
