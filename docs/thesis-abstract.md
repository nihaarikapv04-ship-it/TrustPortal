# Thesis Abstract (`docs/thesis-abstract.md`)

Public-service web portals frequently contain severe accessibility defects, including unlabelled interactive controls, missing image alternative text, and uncaptioned SVGs, creating substantial barriers for citizens relying on screen readers. Existing remediation approaches rely either on static manual authoring or unconstrained automated tools that introduce critical security and privacy vulnerabilities, such as cross-site scripting (XSS), prompt injection, and credential leaks.

This thesis presents **Portal Transformer**, a security-constrained, AI-assisted Chrome Manifest V3 extension designed to perform real-time, client-side semantic accessibility remediation on public-service web portals. Portal Transformer introduces a three-subsystem architecture: (1) a DOM Interceptor that utilizes MutationObserver and deterministic rule-based scanning to detect accessibility defects reactively; (2) a Cloud Inference Relay equipped with a Privacy Firewall and Output Security Validator to extract minimal safe context while scrubbing credentials and filtering untrusted model outputs; and (3) a Hardened Semantic Injection Module that applies reversible patches strictly restricted to an attribute allowlist (`alt`, `aria-label`, `aria-labelledby`, `aria-describedby`, `role`) while yielding to host page re-renders.

The system was empirically evaluated on a synthetic public-service web portal benchmark ($N = 250$ elements). The deterministic detector achieved $100.0\%$ Precision, Recall, and $F_1$ score ($TP=150, TN=100, FP=0, FN=0$). On positive defect items ($N=150$), AI-assisted label generation achieved $100.0\%$ semantic acceptability compared to $65.0\%$ for static deterministic heuristics. Adversarial security evaluations ($N=9$ attack categories) demonstrated a $100.0\%$ rejection rate with zero unsafe DOM mutations. The Privacy Firewall verified zero credential leakage across 7 sensitive input categories. Micro-benchmarks under local mock provider conditions demonstrated a mean total client-side remediation latency of $0.023\text{ ms}$ ($P_{95} = 0.030\text{ ms}$).

These findings demonstrate that client-side AI accessibility remediation can be safely bounded within strict security and privacy constraints. Real-world screen-reader spoken output improvements and live cloud network latency remain subjects for future empirical evaluation.
