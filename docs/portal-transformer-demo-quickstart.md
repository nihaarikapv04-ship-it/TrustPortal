# Examiner Quickstart & Demo Guide (`docs/portal-transformer-demo-quickstart.md`)

> **Quickstart Guide**: Single-page guide for examiners to clone, build, and run the automated demonstration pipeline.

---

## 1. Prerequisites
- Node.js v20.x or higher
- npm v10.x or higher

---

## 2. Single Execution Command

```bash
# Clone repository, install dependencies, build, and launch automated demo pipeline:
npm install && npm run build && npm run demo:portal-transformer
```
